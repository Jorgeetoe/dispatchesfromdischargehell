# /end-session — Save Session State

## What This Does

Captures the current session state and saves it to the "Session State" section of `CLAUDE.md`.

## What to Record

Update the **Session State** section in `CLAUDE.md` with:

1. **Last session date:** Today's date
2. **Session summary:** What was done (e.g., "Staged 2 posts", "Reviewed voice consistency", "Deployed 1 post")
3. **Last published post:** Title and date of most recently published post (if any published this session)
4. **Total published posts:** Count from `site/blog/posts/` directory
5. **Any notes or flags:** Ongoing issues, reminders, decisions

## Example

```
Last session: March 1, 2026
Summary: Staged 1 post ("Flex for Me, Not for Thee"), reviewed voice, deployed successfully
Last published: "Flex for Me, Not for Thee" (2026-01-03)
Total published posts: 37
Current focus: Blog only until 100 posts. No LinkedIn content yet.
Volume goal: 350-500 posts by year-end 2026.
Flags: None
```

---

Run this at the end of each session to keep `CLAUDE.md` current.
