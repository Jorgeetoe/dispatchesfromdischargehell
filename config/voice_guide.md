## Published Blog Voice Rules (locked Feb 25, 2026)

1. **Collective "we"** — Use "we" (not "I") in narrative sections. "I" is acceptable in direct personal anecdotes.
2. **Em dashes — sparingly.** Not every sentence. Use them for emphasis, not as default punctuation.
3. **Common language** with occasional sprinkling — "experience" not "arc." Don't over-polish.
4. **Humanize output more.** If it reads like it was written by AI, it needs more human texture.
5. **No banned phrases:** unlock, streamline, optimize, leverage, robust, comprehensive solution.

## Voice Red Flags (flag these during /stage)

- Reads like a press release or marketing copy
- Generic healthcare complaints without specificity
- Pure cynicism without constructive elements
- Jargon outside the domain (business speak, tech speak)
- Passive voice dominating where active would hit harder
- Every sentence using em dashes
- "I" replacing "we" in narrative sections
- Over-polished — sounds like a TED talk instead of a case manager talking
